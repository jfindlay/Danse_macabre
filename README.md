# Danse macabre — arranged for unaccompanied violin

Camille Saint-Saëns's *Danse macabre*, op. 40 (1874), arranged for solo violin in the work's
original scordatura (G–D–A–E♭). `Program notes.md` is the single exposition: the programme, the
arranging premise and rules, the episode-by-episode rationale, performance notes, provenance.

## Layout

Data flows `source/` → `arrangement/` → `output/`:

```
source/                   INPUT: downloaded or derived reference material (git-ignored)
  lilypond/               the orchestral score's own LilyPond source (download; never edited)
  *.pdf                   full score and the composer's violin/piano reduction (download)
  dump/                   absolute-pitch dump of every orchestral voice (generated by `build dump`)
arrangement/              THE ARRANGEMENT: the only hand-written music
  danse-macabre-solo.ly   main score: \includes global.ily, trame.ily, and episodes/
  global.ily              scordatura header + text/dynamic helper macros
  trame.ily               bar/tempo/key/rehearsal-mark skeleton (carries no notes)
  episodes/               one .ily per episode, bars 1–477 in order
output/                   ARTIFACTS: danse-macabre-solo.pdf, Program notes.pdf (git-ignored)
Program notes.md          the exposition, rendered to output/
build                     build script: score, notes, reference-score tools (see Build)
tools/                    build_dump.py, slice.py, global-stub.ily (behind `build dump`/`slice`)
```

## Source material (fetch before using the tooling)

`source/` is not in the repository; download it first, then run `./build dump` once to generate
`source/dump/`. `./build dump` reads `source/lilypond/`, and `./build slice` and `./build verify`
read `source/dump/`; all three fail without them. The score and notes builds (`./build score`,
`./build notes`) do not need `source/`.

The LilyPond source is the Le Concert 2013 release, the one this arrangement was made against
(`Program notes.md` §5 lists every source with its URL and licence):

```
mkdir -p source/lilypond
curl -L -o source/166-stsaens-dansemacabre-00-lys.zip \
  "https://web.archive.org/web/20150908095230/http://le-concert.pagesperso-orange.fr/st-saens/166-stsaens-dansemacabre-00-lys.zip"
unzip source/166-stsaens-dansemacabre-00-lys.zip -d source/lilypond
```

The 2020 "v.2" re-release is not a substitute: its LilyPond 2.18 syntax differs from the 2013
files that `build dump` upgrades with `convert-ly`.

The two PDFs are reference reading only, not tooling inputs. Download them by hand from IMSLP
(its reverse-lookup pages accept the file numbers) and save them under `source/`:

- `IMSLP272914-PMLP05008-166-full-score.pdf`: <https://imslp.org/wiki/Special:ReverseLookup/272914>
- `IMSLP33277-PMLP05008-violin-piano-reduction.pdf`:
  <https://imslp.org/wiki/Special:ReverseLookup/33277>

## Build

Requires Python 3 and LilyPond (developed against 2.24.3, including `convert-ly`) on `PATH`; the
notes PDF also needs pandoc and xelatex. `./build dump` upgrades `source/lilypond/Mus` with
`convert-ly` in a temp dir and writes `source/dump/`. All finished artifacts go to `output/`.

```
./build          # score + notes
./build score    # output/danse-macabre-solo.pdf
./build notes    # output/"Program notes.pdf"
./build --help   # also the reference-score tools: slice, verify, dump
```

A clean compile reports **zero `barNumberCheck` warnings** — the project's fidelity gate (477 bars
of 3/4, rehearsal marks A–N at the source bar numbers, enforced at every episode boundary). Do not
pass `-dbackend=null`; it crashes during layout on at least one install, independent of this
project.
